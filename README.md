# safonas/tap

Official Homebrew tap for [ocid](https://github.com/safonas/ocid).

## Installation

```sh
brew install safonas/tap/ocid
```

Or add the tap first:

```sh
brew tap safonas/tap
brew install ocid
```

## Included Binaries

- `ocid` — the p2p container distribution daemon
- `ocictl` — the CLI control tool
